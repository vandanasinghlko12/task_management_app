# Reflection Question
## Challenges faced during the project.
One of the main challenges I faced during this project was dynamically displaying tasks on the webpage using JavaScript DOM manipulation. I also found it challenging to create dropdown menus for updating task statuses and filtering tasks based on their status. Handling dates and identifying overdue tasks required extra attention. Another challenge was implementing localStorage to save tasks and ensure they remained available after refreshing the page. I had to understand how JSON.stringify() and JSON.parse() work. Through debugging and practicing, I improved my understanding of JavaScript functions, arrays, objects, event listeners, and DOM manipulation.

## How you approached solving those challenges.
I approached these challenges by breaking the project into smaller steps and working on one feature at a time. I referred to class notes and practiced JavaScript concepts to understand how each part worked. When I faced errors, I used the browser console to identify and fix them. I tested each feature, such as adding tasks, updating statuses, filtering tasks, and saving data in localStorage, before moving to the next step. I also reviewed my code and made changes whenever something did not work as expected. This step-by-step approach helped me improve my problem-solving and debugging skills.

## What you would improve if given more time.
If I had more time, I would improve the design of the application to make it more attractive and user-friendly. I would also add features such as editing and deleting tasks, searching tasks by name, and sorting tasks by deadline. I would improve the overdue task functionality and make sure the data is saved properly in localStorage. I would also add input validation to prevent users from adding empty tasks. Finally, I would make the application responsive so it works well on mobile phones, tablets, and computers
